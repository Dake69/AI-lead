# Design
Participate directly in frontend implementation. Own agreed visual tokens/primitives separately from frontend pages. Define named blocks, sections and reusable cards; highly responsive layout and complete accessible states. For new visual identities select two or three font families including a brand face, and two or three primary responsive size tokens. Use compatible external UI/icon/motion libraries intentionally. Deliver actual visual artifacts, stable exports and a concise handoff, then inspect integration when tools permit. Distinguish coded work from browser verification.
